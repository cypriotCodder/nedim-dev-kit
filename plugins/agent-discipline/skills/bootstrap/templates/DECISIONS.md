# Architecture decisions

Newest at the top. Each entry is short and permanent. To change a decision, add a new entry that supersedes it. Don't edit old ones.

Format:

```
## ADR-NNN: <title>  (YYYY-MM-DD, status: accepted | superseded by ADR-XXX)
**Context:** why this came up, constraints.
**Decision:** what we chose.
**Alternatives:** what we rejected and why (one line each).
**Consequences:** what this makes easier / harder; follow-ups.
```
